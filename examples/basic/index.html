ICONS + LAYOUT

Try an inline Undo action or a dark notification with supporting text. These previews use the real toast API and stay here in the page.

Icons are decorative SVG elements created by the demo. The same icon slot accepts trusted icon-font elements. Text remains plain text; inline actions stack when space is limited.

Use an icon and inline action
const icon = document.createElement('i');
icon.className = 'your-icon-font your-check-icon';
manager.show({
  message: '2 messages were deleted.',
  tone: 'success',
  icon,
  actionLayout: 'inline',
  action: { label: 'Undo', onClick: undoDeletion },
});

Load your icon font separately. Icons are cloned; use application-authored, non-interactive elements. HTML strings are not accepted. Create the manager with showToneLabel: false for these styles.

OPTIONAL ADD-ON

Show five persistent notifications, then drag one horizontally with a pointer to dismiss it. The labeled close button works without dragging.

Try horizontal dragging and vertical scrolling on touch. Keyboard and assistive-technology users can use each notification’s close button. This example uses the package renderer with animation set to none.

Use the swipe add-on
import { createToast } from 'a11y-toast';
import { createSwipeDismissAddon } from 'a11y-toast/addons/swipe-dismiss';
import 'a11y-toast/styles.css';
import 'a11y-toast/addons/swipe-dismiss.css';

const toast = createToast(root, {
  animation: 'none',
  maxVisible: 5,
  addons: [createSwipeDismissAddon()],
});

Toast content and behavior
Timing & announcements

Tone changes appearance, not urgency. Reserve assertive speech for important, time-sensitive information.

Loading always stays visible. Actions and assertive messages stay visible with automatic defaults.

Timed notifications only. The indicator is visual, non-live, and hidden when reduced motion is requested. Change this option when no notification surface is active.

Position can change after all current notifications are dismissed.

Effects work with CSS, GSAP, and supported element View Transitions. None skips motion. Directions name the entrance origin: from top moves down; from bottom moves up. Directional effects exit toward the same origin. Choose an effect when no notification surface is active. Reduced motion skips every effect.

Animation is decorative. GSAP is injected by this development demo. Element-scoped View Transition is experimental and falls back to no motion when unsupported; document-scoped transitions are never used. Reduced-motion preference skips all drivers. Change this option when no notification surface is active.

Optional layout-only motion for surviving notifications. Entrance and exit remain owned by the selected animation engine. Change this option when no notification surface is active.

Experimental ariaNotify falls back to live regions when the API is unavailable. A Permissions Policy can still block ariaNotify silently, so this is not delivery proof.

When hidden visually, the tone text stays available to assistive technology. Change this option when no notifications are active.

Advisory only. Reports are collected silently and appear only when you choose Refresh diagnostics. Change this option when no notifications are active.
