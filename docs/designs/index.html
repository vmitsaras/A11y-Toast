Use Classic light

Use Classic light

Load the base stylesheet, then the skin. Add its class to your toast host. Each skin works independently.

1. Import the CSS

import 'a11y-toast/styles.css';
import 'a11y-toast/skins/classic-light.css';

2. Add the host and trigger

<div class="a11y-toast-region--skin-classic-light" data-toast-host></div>
<button type="button" data-show-toast>Show toast</button>

3. Create and show the toast

// Enable JavaScript to select a matching example.
// The setup and API are also available in the README.

The example includes a decorative inline SVG icon; no icon font is required. Icons, titles and actions are optional. Wide hosts allow inline actions; narrow hosts stack them. Call toast.destroy() when your application removes the host.
